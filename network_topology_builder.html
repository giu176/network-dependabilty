Network Topology Builder

Upload a CSV (Building name, BuildingID, isCore, edge1, edge2, edge3, ...) or edit the table to build a multi-edge network. Drag nodes around and scroll/drag the canvas to explore an infinite workspace.

Data input

Columns: Building name, BuildingID, isCore, edge1, edge2, edge3...
Edges are built from: current BuildingID → edge columns.
isCore: 1/0 (or true/false) to mark core nodes.
